# AfterDay Horizon — Website

เว็บไซต์นำเสนอโปรเจกต์เกมร่วมมือสองคนผ่าน VR และเว็บไซต์

## เปิดดูในเครื่อง

รัน HTTP server ในโฟลเดอร์นี้ เพราะเกมอ่านข้อมูลจาก `seed.json` ผ่าน `fetch()`

```powershell
py -m http.server 8000
```

เปิด http://localhost:8000/ ในเบราว์เซอร์

## หน้าเว็บ

- `index.html` — หน้านำเสนอโปรเจกต์ เรียง 8 ส่วน: หน้าเปิด, แนวคิด, วิธีเล่น, ระบบเกม, การแข่งขัน, คลิป Showcase, แนวคิดการออกแบบ, และทางเข้าเกม รองรับจอคอมพิวเตอร์และมือถือ
- `game.html` — เกมฝั่งเว็บไซต์สำหรับเล่นร่วมกับผู้เล่น VR ด้วยรหัส ใช้จอคอมพิวเตอร์
- `game.html?demo=1` — โหมดทดลองฝั่งเว็บไซต์ด้วยข้อมูลตัวอย่าง ใช้ได้โดยไม่ต้องมีชุด VR

เมื่อเข้าเกมบนคอมพิวเตอร์ จะมีคำแนะนำที่ชี้ปุ่มจริงบนหน้าจอแทนภาพ tutorial แบบเลื่อน ผู้เล่นทดลองเปิด ReadME ไฟล์คู่มือ แฟ้ม และระบบต่าง ๆ ได้ตามลำดับที่ต้องการ เวลาภารกิจหยุดระหว่างฝึก และเริ่มเมื่อสำรวจครบหรือเลือกข้าม
- `img/` — ภาพหน้าจอ ภาพการแข่งขัน สรุปรางวัล และคลิปการเล่นจริง

บนมือถือสามารถอ่านโปรเจกต์และดูคลิปได้ ตัวเกมฝั่งเว็บไซต์ออกแบบสำหรับจอคอมพิวเตอร์

หน้าแนะนำมีปุ่มสลับภาษาไทย/อังกฤษ วิดีโอ Showcase `img/cdve/showcase.mp4` ที่เล่นอัตโนมัติแบบปิดเสียงและวนซ้ำ สี่ขั้นตอนที่เปลี่ยนภาพเมื่อ hover หรือแตะ การ์ดระบบที่กดดูภาพฝั่งเว็บไซต์และ VR พร้อมผลของการทำงานร่วมกัน และแท็บผลงาน NAPROCK PROCON 2024 กับ CDVE 2025 ภาพผลงานกดดูข้อมูลทีมและอาจารย์ที่ปรึกษาได้

คลิป Showcase เต็มอยู่ใน section 06 โดยใช้ไฟล์เดียวกัน และตั้งค่าให้เริ่มโหลดเมื่อผู้ชมกดเล่น เพื่อลดการโหลดข้อมูลซ้ำบนหน้าแรก

## Deploy

โปรเจกต์นี้เป็นเว็บไซต์ static ไม่ต้องมีขั้นตอน build ให้นำไฟล์ใน `AfterDayHorizon-deploy.zip` ไปแตกไว้ที่โฟลเดอร์เผยแพร่ของโฮสต์ โดยให้ `index.html`, `game.html` และ `seed.json` อยู่ที่ระดับบนสุด โฮสต์ต้องเสิร์ฟไฟล์ JSON และ MP4 ได้ตามปกติ

หลังเผยแพร่ ให้เปิดหน้าแรกและ `game.html?demo=1` เพื่อตรวจการโหลดรูป คลิป Showcase และข้อมูลเกม ปุ่ม Behance ที่แถบด้านบนเปิดผลงานในแท็บใหม่
